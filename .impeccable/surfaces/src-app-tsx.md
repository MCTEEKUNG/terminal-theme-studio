## Direction contract

THESIS: A monochrome dark glass workspace with a compact settings inspector on the left and the large terminal preview on the right. The user chose B and explicitly pinned this layout and material; Dark Glass is the main interface; remove comparison controls and alternate design routing.

OWN-WORLD: User-pinned modern glassmorphism: #090909 ground, translucent neutral black panels, thin white borders, #f5f5f5 primary type, #b8b8b8 supporting type, #eeeeee primary actions with #111111 labels. No chromatic Web UI accents. Terminal schemes, palette specimens and user media retain their true colors. Hanken Grotesk for UI and user-selected terminal fonts. Backdrop blur belongs to the two actual glass work areas and header; an opaque fallback preserves legibility. No animated decoration.

STORY: Select B, browse 24 real presets, select a theme, inspect output, tune typography/transparency/background, save the look, open the actual terminal. Application styling is independent of terminal preferences.

The ordered eight-color specimen ribbons remain content. Selection changes use 160ms transitions and respect reduced motion.
